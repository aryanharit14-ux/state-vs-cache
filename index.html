Understanding Long-Horizon Evolving State

“A fixed-shape recurrent state can process a sequence of unbounded duration without allocating a new memory slot for every token, but it can still forget through interference.”
unbounded duration
The state representation does not grow with sequence length — the matrix stays D×D regardless of how many facts are written into it.
can still forget
Information capacity is still limited — the finite D×D matrix cannot faithfully represent arbitrarily many stored facts.
through interference
Demonstrated live below, not asserted. Move the sliders and watch retrieval degrade when N exceeds D’s effective capacity.

This experiment stores N random key→value facts in two different memory systems, then queries every key and measures retrieval accuracy. The growing cache allocates one dictionary entry per fact. The recurrent state compresses all N facts into a single fixed D×D matrix via additive outer-product writes. Adjust N and D to observe when and how retrieval degrades.

Why did it forget?

Every write does σ += outer(key, value) — a rank-1 update. With N small relative to D, random unit vectors in D-dimensional space tend to be nearly orthogonal, so each stored fact occupies a nearly distinct “direction” inside the matrix. A query key activates mostly its own stored direction, and retrieval succeeds.

As N grows beyond D’s effective capacity, non-orthogonal key vectors accumulate inside the same shared matrix. A query key now partially activates the directions of other stored facts, producing a blended raw output. The nearest-value search picks the closest stored value vector to that blended output — but under high interference, that is no longer the correct one. This is interference. It is not a bug; it is a capacity limit.

BDH Connection

The Mechanism Behind This Toy

How this experiment relates to the BDH (Dragon Hatchling) architecture. The write/read rules used in this toy share their mathematical structure with the idealized formulation described in Pathway’s

“From attention to synapses: deriving BDH” — Ch. 2, BDH Explainer Series
σt = σt−1 + xtT vt   ← synaptic state update (write)
ot = xt · σt   ← read
Scope of this analogy. Our toy’s write/read rule — σ += outer(key, value), read = key @ σ — has the same additive outer-product write/read structure as the idealized BDH formulation shown above. It is not a reproduction of the trained BDH architecture: our toy uses a small engineered key/value retrieval task, while BDH has additional learned dynamics and nonlinearities layered on top of this mechanism.

What this toy omits from BDH’s real design

  • ReLU nonlinearity and enforced sparse, non-negative activity — BDH uses these to maintain stable, interpretable internal representations.
  • The transition operator U — handles positional and decay effects in BDH’s real system; our toy has no temporal ordering beyond write sequence.
  • Low-rank factorization (E, Dx, Dy) — used in BDH for GPU efficiency; our toy uses a full D×D dense matrix.
BDH vs. a Transformer’s KV cache: In BDH’s architecture, the runtime memory is a fixed-size synaptic state whose effective context length is bounded by information capacity rather than by sequence length — meaning more tokens can be processed without the memory structure itself growing. This contrasts with a Transformer’s key-value cache, where every new token appends a new entry, causing memory to scale linearly with sequence length. The BDH approach trades the Transformer’s per-entry isolation for the ability to process very long sequences inside a structure that does not expand.
Related: BDH-CQ (Pathway, Aug 2026) — A related system in the same family that adapts via recurrent state at inference time without updating its parameters, enabling test-time specialization. Secondary to the core BDH discussion above.
Key Observation

“Fixed-size state removes the need to grow memory with every token, but fixed capacity does not mean unlimited information storage. Information can interfere inside the state.”

Limitations of This Demo

Limitations

Within-run interference vs. real long-context behavior. This toy conflates within-a-single-run interference (N random facts compressed into one fixed matrix) with BDH’s actual reported long-context behavior across its training distribution and real benchmarks. We are not claiming this toy reproduces BDH’s ARC-AGI-1 benchmark results, its long-context evaluations, or any published numbers. The toy illustrates one isolated mechanism — the additive outer-product write — and its inherent capacity limit under random, non-orthogonal keys. Real BDH manages this through nonlinearities, learned dynamics, and a very different training regime. This is labeled explicitly as an educational reimplementation of one isolated mechanism.
